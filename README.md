# TypeScript Regex Playground & Debugger (`ts-regex-playground`)

An advanced, feature-rich Regular Expression debugging and pattern-analysis workspace built with React, TypeScript, and Tailwind CSS.

## Features

- **Live Pattern Matching & Validation:** Real-time regex evaluation engine with syntax error reporting.
- **Match Inspector & Capture Groups:** Detailed telemetry for match indices, full matched strings, and numbered capture groups.
- **Curated Template Library:** Pre-loaded security and web patterns (IPv4, RFC Emails, JWTs, UUIDv4).
- **Flexible Flag Controls:** Toggle global (`g`), case-insensitive (`i`), multiline (`m`), dotAll (`s`), and unicode (`u`) flags.

## Setup & Running

1. Clone repository & install dependencies:
   ```bash
   cd ts-regex-playground
   npm install
   ```
